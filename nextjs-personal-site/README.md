# Sushil Lamichhane — Personal Website

A Next.js + TypeScript starter for a combined professional portfolio and academic profile.

## Current milestone
- Premium dark/light visual direction
- Responsive homepage
- Sections for About, Teaching, Projects, Research, and Contact
- Metadata and semantic HTML

## Run in a browser-based development environment
Requires Node.js 20.9+.

1. Open this repository in GitHub Codespaces.
2. Open a terminal and enter the project directory: cd nextjs-personal-site
3. Install dependencies: npm install
4. Start development: npm run dev
5. Open forwarded port 3000 to preview the site.

## Before publishing
- Replace the placeholder email hello@example.com in app/page.tsx.
- Add only accurate education, employment, skills, project, and research details.
- Configure a real contact form before promising form submissions.
- Add Supabase authentication and database policies before building the private admin dashboard.
- Never commit .env files, passwords, API keys, or service-role keys.
